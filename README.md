# GeoPulse – Hyper-Local Retail Mobility Analytics

## Project Overview
GeoPulse is a geospatial analytics project designed to understand customer movement, retail store footfall, and location-based retail opportunities.

## Business Objective
To analyze anonymized mobile GPS location data and identify customer traffic patterns around retail store locations.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Snowflake
- Apache Sedona
- PySpark
- dbt
- Kepler.gl

## Week 1 – GPS Data Generation
- Generated 5,000 simulated GPS records.
- Created anonymized DeviceIDs.
- Generated Latitude and Longitude coordinates.
- Created timestamp data representing seven days of city movement.
- Saved the dataset in CSV format.
